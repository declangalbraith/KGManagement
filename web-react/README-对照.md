# web-react 对照说明

本目录为 **React 业务原型**（`remix_-qconnect`），主前端已迁移至 `../web/`。

## 用途

- 交互与文案对照
- Mock 数据结构参考（如 `modules/quality-docs/mocks/`）
- 未迁完的细节 UI 可参考后补到 Vue

## 不再作为交付物

新功能请在 `web/src/views/system/` 开发，路由登记在 `web/src/router/businessRoutes.ts`。

## 启动（可选）

```bash
cd remix_-qconnect
pnpm install
pnpm dev
```
